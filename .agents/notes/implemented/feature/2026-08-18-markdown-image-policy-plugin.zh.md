# Agent Note: 会话级 Markdown 图片策略

Status: implemented

[English](2026-08-18-markdown-image-policy-plugin.md) | 中文

## 问题

自动显示 Markdown 图片很实用，但 assistant 可能受诱导而把模型可见 secret 放入图片 URL。把该 URL 赋给 `<img src>` 会让浏览器在不经过工具权限的情况下披露它。阻止所有图片或要求每张图片都点击会破坏预期的 Markdown 体验，而阻止本地路径又会使普通的 agent 生成产物无法出现在会话中。

## 决策

`@deepseek-ai/dsh-client-ui-markdown-images` 是默认 Web bundle 挂载的宿主/客户端插件。其浏览器半侧通过会话标准 prop registry 为每个投影会话贡献一个 resolver。`MarkdownText` 以普通 prop 接收 resolver 和稳定渲染持有方；后者只用于本地附件身份。

`inspectRemoteImageUrl(source)` 是只读取创作源字符串的纯函数。它不执行 I/O、会话日志查询、浏览器状态访问或 URL 重写。不含嵌入凭据、且未识别出 secret 的公共 HTTP(S) URL 会按原样自动加载。宿主使用固定版本的 `@sanity-labs/secret-scan` 检查去除 fragment 后的请求 URL，并对路径与查询字段进行一次百分号解码检查；任何 high 或 medium 置信度匹配都需要确认。不支持的 scheme 与嵌入凭据仍受阻。

本地名称与字面私有网络 HTTP(S) 目标同样需要确认。精确的 `trustedOrigins` 条目可让其私有 origin 自动加载，但绝不会绕过 secret 检测。策略不解析公共 DNS 名称，不特殊处理公共同源 URL；获准的远程 URL 仍由浏览器直接请求，并采用延迟加载、异步解码及 no-referrer。

确认结果会显示图片形按钮，且不会先设置 `<img src>`。悬停与键盘聚焦都会披露本地化的策略原因，该文本同时也是按钮供辅助技术读取的描述。alt 文本为空时使用通用标签，不会暴露创作 URL。激活会直接设置创作时的原始源字符串；该操作不会再次请求宿主，也不会创建持久授权。批准属于当前挂载的持有方与源字符串，因此替换、卸载、重新加载或回放都会恢复占位图。

相对路径从会话工作目录解析；绝对 POSIX 与 Windows 路径和有效的本地 `file:` URL 通过 `ctx.fs` 读取。PNG、JPEG、WebP 与 GIF 字节通过 `ctx.attachments` 保存，其验证与限制仍是权威规则。映射键对会话 ID、稳定渲染持有方和创作源字符串做哈希。`<DSH_HOME>/markdown-images/v1/mappings` 下的私有原子记录只含附件引用。回放读取原始附件；附件缺失或损坏时会阻止显示，而不会捕获已经变化的源字节。同一键的并发请求共享一次导入。

## 接受的残余风险

Secret 扫描是概率性的。提供方模式与部分熵规则不能识别任意机密文本，因此公共 hostname、路径或查询中的未识别值会自动加载。公共 DNS 可能在检查后解析到私有地址，重定向仍由浏览器负责，远程 origin 会收到浏览器的普通请求，以及浏览器策略为该 origin 发送的任何凭据。误报需要一次点击，而点击会明确接受完整原始 URL。

## 考虑过的替代方案

**把所有图片都渲染为 alt 文本。** 这会关闭自动图片流量，但也会从正常会话体验中移除网络图、截图与本地产物。

**每张远程图片都必须点击。** 这会让每次普通显示都需要交互。确认只用于识别出的 secret 与字面私有目标，因此普通 Markdown 行为仍是自动的。

**通过会话来源授权或重写 URL。** 会话历史、渲染截止点与查询重建会增加跨事件状态，同时仍无法发现新颖位置中的 secret。只依赖 URL 的检查具有确定性，并保留签名或其他有意义的 URL。

**通过宿主获取并持久化所有图片。** 完整代理还需要重定向、DNS rebinding、出口、认证、解压、媒体与大小策略。远程请求保留在浏览器中，本地文件则使用现有文件系统与附件权限。

**缓存附件不可用时重新读取本地源。** 这会使历史会话呈现依赖可变文件系统状态。保持终止且可见的失败可以保留回放身份，并暴露存储损坏。

## 后果

默认 Web 会话、trajectory、compaction 卡片、计划与提问界面以及工具/Web 呈现共享一个只依赖 URL 的远程策略和一个持久本地导入器。安全图片自动加载，可疑目标提供仅限一次渲染的显式批准，本地图片在源文件删除后和历史重新加载时仍可显示。插件增加可信宿主 RPC 与私有映射存储，但不增加会话格式事件、Settings UI、远程图片缓存、SVG 支持或 AttachmentStore 扩展。测试固定纯 URL 检查、精确源字符串保留、确认生命周期、私有 origin 例外、本地导入身份、resolver 清理、流式稳定性及组装浏览器行为。
